# LF:s byggprocess mot modellen + ordlista

Modellen ersätter inte Lejonguiden — den lägger ett gemensamt styrlager ovanpå.
Modellen = skalet (hur projektet styrs: faser, BP, roller, dokument).
Lejonguiden = köttet (branschspecifikt: delprocesser, interna mallserier
LM/LI/LR/LD, system som projektverktyget Antura, kontrollpunkter).

**Lokalförsörjningsprocessen är inte projektet.** Behovsanalys, lösa lokalbehov
och utredning är linjearbete (fasen Behov/Idé) som *beställer* projektet. Med
BP 1 får projektet ett formellt startskott.

## LF:s byggprojektprocess (totalentreprenad) under modellen

| Fas | LF-moment |
|---|---|
| Behov/Idé (linje) | Lokalförsörjningsplan · lösa lokalbehov · utreda möjlig lösning |
| Förbereda | LSA ansvarar; FU/Inhyrning utreder och gör ev. förstudie på uppdrag; projektdirektiv inför BP 1 |
| Planera (före BP 2) | Program-/utredningsskede → programhandling · framskrivning (det politiska beslutsunderlaget) → investeringsbeslut · hyresöverenskommelse + politiskt beslut |
| Genomföra | Systemhandling (LF projekterar) · upphandling av TE på systemhandling · detaljprojektering (TE) · produktion · slutbesiktning |
| Avsluta | Lämna över lokal · avsluta projekt · slutreglering |
| Effekt | Nyttoutvärdering · garantibesiktning (2 år) |

**Tre överlämningar:** 1) LSA → projekt vid BP 1 · 2) FU → projektledare vid
BP 2 (efter investeringsbeslut) · 3) Projektledare → förvaltning vid BP 5.

Förkortningar: **LSA** = lokalstrategiska avdelningen · **FU** =
fastighetsutveckling · **Inhyrning** = LF:s enhet för inhyrda lokaler ·
**TE** = totalentreprenör.

## Ordlista: byggterm ↔ plats i modellen

| LF/byggterm | Plats i modellen | Kommentar |
|---|---|---|
| Lokalförsörjningsplan | Behov/Idé | Linjearbete före projektet |
| Förstudie | Fas Förbereda | Kan drivas som separat uppdrag |
| Förstudierapport | Underlag för BP 1 | Slutleverans i Förbereda |
| Programhandling | Fas Planera | Levereras före BP 2 |
| Framskrivning / investeringsbeslut | Fas Planera | Beslutsmoment mellan BP 1 och BP 2 |
| Hyresöverenskommelse + politiskt beslut | Fas Planera | Bindande externt åtagande — tecknas före BP 2 |
| Systemhandling | Fas Genomföra | Påbörjas först när hyresöverenskommelsen binder åtagandet vid BP 2 |
| Upphandling av totalentreprenör | Fas Genomföra | På systemhandling — föregår detaljprojektering |
| Beslut att teckna entreprenadkontrakt | BP 3 (valfri) | Naturlig BP 3-kandidat |
| Bygghandling, produktion | Fas Genomföra | TE projekterar och bygger |
| Slutbesiktning | Underlag för BP 4 | Tekniskt godkännande — kompletteras med leveransgodkännande mot projektmålen |
| Lämna över lokal, avsluta projekt | Fas Avsluta | Avslutas med BP 5 |
| Garantibesiktning (2 år) | Fas Effekt | Efter projektet |
| Hyresgästen | Mottagare | Tar emot lokalen; LF:s förvaltning är mottagare för drift |
| Projektanmälan | Parallellt LF-internt | Digital workflow enligt delegeringsordningen; ingår inte i kommunens modell |

**Vanlig förväxling:** Lejonguidens interna BP-numrering och modellens BP 1–5 är
helt orelaterade. Mot förvaltningarna gäller alltid modellens BP 1–5.
